# Bundle d’emojis custom

Ce document sert à préparer des emojis custom pour **답답한 분위기 V2**.

Le bot custom ne crée pas, ne synchronise pas et ne gère pas les emojis. L’ajout se fait manuellement dans Discord.

## Style recommandé

- Dark
- Premium
- Gaming
- Anime sobre
- Lisible en petite taille
- Fond transparent si possible

## Emojis utiles

Navigation :

- `gold_star`
- `night`
- `rules`
- `guide`
- `roles`

Gaming :

- `valorant`
- `minecraft`
- `ranked`
- `lfg`
- `controller`

- `anime`
- `movie`
- `music`
- `creative`

Activité :

- `event`

- `poll`

Staff :

- `admin`

- `warning`

## Format conseillé

- PNG ou WebP
- 128x128 px
- Taille inférieure à la limite Discord
- Noms courts, sans espace, en minuscules

## Installation manuelle

1. Ouvre les paramètres du serveur Discord.
2. Va dans **Emoji**.
3. Upload les fichiers un par un.
4. Renomme-les avec les noms prévus.
5. Teste leur affichage dans un salon privé staff.

## Utilisation avec Sapphire

Tu peux utiliser ces emojis dans :

- embeds de règlement ;
- panneau de rôles ;
- boutons ou réactions de validation ;
- panels de notifications.

Sapphire gère l'usage des emojis dans ses panels de validation et de rôles. Le provisioning bot custom ne le fait pas.

## À éviter

- Emojis illisibles en petit.
- Emojis trop proches visuellement.
- Emojis liés à des marques si tu n’es pas sûr de pouvoir les utiliser.
- Trop d’emojis animés, souvent moins lisibles.
